Right Side Wiper and Washer (When Equipped)
To operate the right side wiper and washer system the key switch must be in the RUN position.
The right side wiper/washer control is on the right side of the steering column. The operator activates the
right side wiper by moving the right side wiper switch on the control lever to the desired speed. Each
speed position creates a different path to ground. The minipod senses the different ground paths. The
position of the wiper switch is sent over the OSD CAN bus to the OSDC. The OSDC interprets the message
and then powers the necessary circuits to energize the right side wiper motor.
The right side wiper moves back and forth across the window at the selected speed. The wiper will only
swipe back and forth for approximately 8 seconds. The wiper completes its path across the window and
returns to the wiper park position.
When the right side washer switch is selected, a different path to ground is created. The minipod senses
the ground path and sends an OS domain CAN bus message to the OSDC. The OSDC interprets the
message and broadcasts a vehicle CAN bus message to the PODC. The PODC receives the message and
then powers the circuits to energize the right side washer motor. Washer fluid is sprayed onto the window
for several seconds. At the same time as the fluid is sprayed on the window the wiper is activated. When
the operator releases the washer button, the wiper makes about two additional swipes on the window and
returns to the parked position.

The boom control hydraulic unit (BCHU) functions as a gateway, connecting BoomTrac CAN bus with
implement CAN bus.
Each boom contains multiple cameras, ultrasonic height sensors (UHS), inertial measurement units (IMU),
and vision processing units (VPU). Information is processed by the VPU to command the spray action of the
nozzles. This includes images gathered by the cameras, boom pose information measured by the IMU,
boom distance away from the ground, and the crop canopy measured by the UHS. Each sensor is a
miniature electronic control unit that sends the gathered information as a binary (digital) CAN message to
the BCHU.
Accuracy increases as the boom gets lower. When the boom is at a greater height, singular weeds are
caught by more cameras. The VPU receives this information and commands multiple nozzles to spray,
which causes overlapping. When the boom is at a lower height, singular weeds are caught by fewer
cameras. The VPU receives this information and commands fewer nozzles to spray, which causes a more
precise application.

Machines equipped with ExactApply (the solution spray nozzle system) are equipped with an ExactApply
controller area network binary unit system (CAN bus).

CAN bus systems transfer messages between every control unit on the machine. These messages include
commands, requests, broadcast information, responses, acknowledgments, and various group functions.
The CAN bus is a linear network, and the control units are connected along its length in series.
The operator has no direct control of the CAN bus systems. CAN bus operates automatically whenever the
key switch is in the ACC, RUN, or START positions.

Technical Manual (DTM).

Aftertreatment ΓÇö Electrical Theory of Operation
The aftertreatment device (ATD) passively and actively captures the particulate matter (soot) from the
engine exhaust gas. The aftertreatment process cleans the engine of hydrocarbons and nitrogen oxide
(NOx). In total, the machine aftertreatment regenerates the engine exhaust, producing only clean nitrogen
gas and water vapor.
Component Information:
Exhaust gas enters the diesel oxidation catalyst (DOC) chamber and then flows through the diesel
particulate filter (DPF). The DOC actively oxidizes hydrocarbons, while the DPF passively captures
particulates. Constant monitoring of exhaust gas temperature allows the electronic control unit to manage
this regeneration process.
There are two aftertreatment NOx sensors. The NOx sensor, located at the DPF outlet, and the
aftertreatment outlet NOx sensor, located at the selective catalyst reduction (SCR) outlet. These sensors
monitor emission levels and machine NOx conversion efficiency. The engine control unit (ECU) provides
power for both sensors.
Information from these sensors, travels along the engine controller area network (CAN) binary unit system
(bus) high and low circuits and into the ECU. The ECU uses this information to assess the NOx conversion
efficiency.

Diesel exhaust fluid (DEF) converts NOx into nitrogen gas and water vapor. The SCR injects a high purity
urea-based additive into the exhaust system cleaning the engine emissions.
The DEF fluid temperature sensor and DPF differential pressure sensor measures the initial output from
the turbocharger and DPF.
The DEF dosing injector then mixes high purity urea-based additive into the exhaust line, which converts
NOx into nitrogen and water.
DEF tank header assembly, SCR supply module, and DEF dosing line heaters (when in good working order),
allow the DEF dosing injector to function correctly. The DEF tank assembly allows coolant flow when
needed. It also measures the fluid level and temperature. DEF supply module pumps DEF from tank to the
dosing injector. When the temperature is cold, DEF dosing unit heater and DEF dosing line heaters keep
the lines from freezing.
The ECU powers and controls all DEF and SCR components. Signals return to the ECU and, when needed,
information passes to the corner post display (PDU) through CAN bus circuits.
For more detailed information on the aftertreatment system, see the appropriate engine component
technical manual (CTM).

Fuel Level Sender ΓÇö Electrical Theory of Operation
Fuel level is displayed on the corner post display as a segmented gauge for the operator. When the level
reaches 10% remaining fuel, the fuel indicator flashes, an alarm sounds, and a low fuel message appears.
Component Information:
The system is active whenever the key switch is in the RUN position.
The fuel level sender is a variable resistor that provides a signal output proportional to the fuel level in the
tank. The greater the fuek volume, the higher the resistance. When the fuel level is lowest, there is no
resistance across the sensor.
The powertrain domain control unit (PODC) monitors the fuel level and a vehicle controller area network
(CAN) binary unit system (bus) message is sent to the PDU where the fuel level is displayed.
For additional information, refer to the appropriate engine component technical manual (CTM).

Fuel Transfer Pump ΓÇö Electrical Theory of Operation
When commanded by the engine control unit (ECU), the fuel transfer pump solenoid valve delivers
necessary fuel from the fuel tank into the high-pressure pump.
Component Information:
Fuel level information is sent from the ECU to the fuel transfer pump when the key switch is turned to the
RUN position. Power continuously flows from the mid-chassis load center and relay block into the fuel
transfer pump.
The ECU enables the fuel transfer pump to run for one minute, allowing the fuel system to prime and bleed
any air from the fuel supply. If the engine is not started after this time, then the ECU automatically
switches off the fuel transfer pump.
For additional information, refer to the appropriate engine component technical manual (CTM).
