The address/sync circuit allows the VPU to know its physically installed location on a machine. From the address circuit frequency input, the VPU is able to report the
proper unique identifier on each CAN bus.
The VPU must claim addresses on both CAN busses. The VPU uses the same source address for all CAN busses.
Each VPU's unique location is required for See & Spray to function properly. See & Spray software uses its unique boom location to identify each camera's input, their
corresponding nozzles, and which calibrations to use. If identification of each VPU's unique boom location fails, the VPU is unable to interpret camera inputs.
Addressing works by adjusting the address/sync circuit frequency (in Hz) for each subsequent VPU. This frequency change provides a unique software identifier (VS1,
VS2, VS3, or VP1, VP2, VP3, etc.) that corresponds with each VPU number.
When any VPU is unable to address using an input frequency at power-up:
The addressing circuit is a series (daisy-chain) circuit. If the circuit is open, the daisy-chaining addressing process is unable to complete at the point of failure to
downstream VPUs. All downstream VPUs report an addressing failure. To promote uptime, the VPU has a feature in which it stores the last known successful installed
location. If the VPU is unable to address from an input frequency, it determines if it has a last stored location. If this is true, the VPU establishes its location as the
stored last known location.

Each CAN bus network has two terminators, located at each end of the CAN bus. Terminators provide the
proper resistance required between CAN Lo and high signal circuits. Terminators provide message
termination at either end of the circuit. This way, messages cannot bounce back through the circuit and
cause false signals.
Each passive CAN bus terminator is a 2-pin 120 ╬⌐ resistor.
These resistors provide passive termination ΓÇö neither power nor ground is supplied at the terminator.
These resistors regulate CAN Hi and CAN Lo circuits, verifying that each circuit stays within the appropriate
ranges.
Each active CAN bus terminator is a 6-pin or 9-pin connector. Active CAN bus terminators use machine
power to provide 12 V power and ground to two extra circuits: CAN power and CAN ground. These circuits
provide active voltage regulation and protection against changes in the magnetic field. The CAN power
and CAN ground circuits protect CAN Hi and CAN Lo circuits from reading these magnetic field changes as
false signals.

See & Spray Wakeup ΓÇö Electrical Theory of Operation
The Gateway Control Unit provides the system wakeup power to vision processing units (VPUs). VPU
wakeup occurs in two steps, first with the lead VPU and then once active, the remaining VPUs.
The gateway costrol unit (GWC) (A725) receives wakeup power from the machine control unit wakeup
power system. Once active and either the engine is running or VPUΓÇÖs enabled using the diagnostic address,
the GWC energizes the ELX group 1 circuit, circuit 0126. ELX group 1 provides wakeup power to the lead
vision processing unit (VPU 6) (A716) and Ethernet switches 1ΓÇô3 (A726ΓÇôA728). CAN messages between VPU
5 and the GWC verify for the GWC that VPU 5 is active, allowing the GWC to energize the ELX group 2
circuit, (circuit 0136), which provides wakeup power to the remaining VPUs (A711ΓÇôA715 and A717ΓÇô720).
System shutdown follows the same process that the other machine control units follow. Messages
between the GWC and VPUs allow the controllers to shutdown before power is removed from the ELX
circuits.
Wakeup power to the VPUs and ethernet switches is provided by the GWC.
The wakeup ELX circuits are independently grounded from the machine ground via the combined ELX
ground circuits, (circits 0120/0130), to the center frame right-hand ground buss bar (GND305).

implement functions at once. The purpose of the quick-stop safety control system is to provide the ability
to avert harm or to reduce harm to people and machinery.
CAUTION:
When pressing the quick-stop switch, the operator is responsible for pulling back on the multi-
function lever to stop the machine.
It is always recommended to wear your seat belt to avoid serious injury.

(ARMC) monitors the condition of the quick-stop switch.

message on the operator station domain (OSD) CAN bus to the operator station domain control unit
(OSDC).
The OSDC then sends the message out to the other control units on the vehicle and the implement CAN
buses. Once the other control units receive the message, the following systems, depending on system
being utilized, are disabled:
Disabled functions are restarted by activating the corresponding switches or by cycling the corresponding
function switch from ON to OFF, then to ON again.
