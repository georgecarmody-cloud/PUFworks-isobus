VPU ΓÇö Electrical Theory of Operation
The vision processing unit (VPU) is the image processing module (IPM) that identifies live plants (green color) within an image. When an image is captured by a green
detection camera on the boom, the VPU analyzes the image for green color spectrum within the image. The VPU interprets the objects size and determines whether
to send spray message to the corresponding nozzle body to spray the object. When See & Spray Ultimate is active, only valve B of the individual nozzle responds to
commands from the VPU to spray.
Component Information:
The VPU communicates on both BoomTrac controller area network (CAN) binary unit system (bus) and the respective ExactApply nozzle subnet CAN bus. The
BoomTrac CAN bus is required to know the boom height for the proper camera region of interest to be used for image capture. The BoomTrac CAN bus also allows
for communication to the gateway control unit (GWC) for user interface to the VPU.
For correct weed analization, each aspect of the See & Spray system must communicate with each other appropriately. The cameras on the boom communicate
through coaxial cable to the VPU for weed detection. The GWC and BoomTrac communicate to the VPU through BoomTrac CAN. The individual nozzles communicate
through ExactApply CAN. Modular telematics/display communicates through the Ethernet system to the gateway control. The GWC communicates the information
back to the Generaion 4 Display on the implement CAN bus. The GWC reports issues by displaying GWC diagnostic trouble codes (DTCs).
Unswitched power is a constant 12 V power supply that comes directly from the batteries and battery disconnect switch. Power is supplied to the See & Spray load
center via the ExactApply load center. Power is supplied from the mid-chassis power distribution center to the EA load center and on to the See & Spray load center
(on the fixed center frame) with 12 V power circuit, protected by a 150A fuse master nozzle control/See & Spray fuse within the mid-chassis power distribution load
center.

The agitation system consists of an electric motor that turns a ball valve in the solution system to start and
stop agitation. Agitation flow is set with how far the agitation valve is opened and where the spray-off
pressure is set. Three agitation levels can be chosen from the display:
Agitation levels can be further adjusted by altering the solution pump speed. The icon for the agitation
level indicator on the PDU illuminates when agitation is active and displays the amount that the valve is
opened.
To stop agitation, press the solution pump button to stop the pump, then press the agitation button to
close the agitation valve. Additional information can be found withing the appropriate Operator's Manual
(OM).
In Cab Agitation Switch
When agitation is commanded, a message is sent to the operator station domain control unit (OSDC). The
OSDC then sends a message on the implement controller area network (CAN) binary unit system (bus)
indicating that the agitation has been commanded.
The PSSC for system 2 receives the message and sends a request on the implement CAN bus to the
agitation valve motor. The SSSC receives the message and sends a request on the secondary solution
control CAN bus to the system 1 agitation CAN valve motor. The requests to the agitation valve motors
move the valve to the desired position based on the rate selected.
Dual System Keypad
When the agitation switch on the dual system keypad is pressed to activate system 2 agitation, a message
is sent on the implement CAN bus to the PSSC. The PSSC then sends the message to the agitation valve
motor. The agitation valve then moves to the desired position based on the rate that has been selected.
When the agitation switch on the dual system keypad is pressed to activate system 1 agitation, a message
is sent on the implement CAN bus to the SSSC. The SSSC then sends the message on the secondary
solution control CAN bus to the system 1 agitation CAN valve motor. The agitation valve then moves to the
desired position based on the rate that has been selected.
Agitation Valve
The agitation valve motors receive position commands and report position status on the implement and
secondary solution control CAN buses.
Ground for the agitation systems are provided by the battery box ground and solution skid ground buss
bar.

CommandARM Control Modules ΓÇö Electrical Theory of 
Operation
The CommandARM contains four modules, which allow the operator to control machine navigation and
implement functions. For detailed operation of the controls, see the appropriate OperatorΓÇÖs Manual (OM).
Component Information:

module connects to the ARMC through a local interconnect network (LIN) binary unit system (bus). The
ARMC connects to the operator station domain control unit (OSDC) through the operator station domain
CAN bus. The OSDC sends the ARMC signals along the implement CAN bus and the vehicle CAN bus.
Driving Controls Module (DCM)
The DCM allows the operator control of settings such as the park brake, engine speed, and transmission.
The DCM communicates directly with the ARMC.
House Controls Module (HCM)
The HCM allows the operator control of exterior lighting, infotainment radio and the heating, ventilation,
and air conditioning (HVAC). The HCM communicates with the ARMC on the ARMC LIN bus 1.
Settings Control Module (SCM)
The SCM allows manual control of the implement functions. The SCM communicates directly with the
ARMC.
Navigation Bar
The navigation bar provides quick access to different applications. The navigation bar communicates with
the ARMC on the ARMC LIN bus 1.
